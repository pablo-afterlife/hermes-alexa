# hermes-alexa

A Alexa como canal nativo do [Hermes Agent](https://github.com/NousResearch/hermes-agent):
fale com o Hermes pelo Echo e deixe o Hermes falar de volta, **sem tirar a Alexa**.

> 🚧 Em construção (Fase 0: viabilidade). Ainda não dá para usar.
> 🇺🇸 [Read in English](README.md)

## O que vai fazer

- "Alexa, pede pro Hermes …" → o Hermes responde no mesmo Echo, com memória e ferramentas.
- Tarefa longa: a Alexa confirma na hora e o Echo anuncia o resultado quando o Hermes terminar.
- O Hermes faz qualquer Echo falar, anunciar ou executar comandos da Alexa a partir de
  qualquer canal, agendamento ou gancho.

Arquitetura (em inglês): [docs/architecture.md](docs/architecture.md).
